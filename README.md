# GSBA594 Python Assignments
## Project Overview
This project is an in-class Python assignment using the Pandas library to analyze weather data.  The dataset contains 13,200 observations and 11 columns.

The notebook demonstrates basic data analysis skills, including importing a CSV file, examining the dataset, and answering questions using Python.

## Files included


- In-Class Assignment Sep.20 (1).ipynb - Jupyter Notebook containing the Python assignment.
- weather_classification_data.csv - Weather dataset used in the analysis.

## How to Run the Project
1. Download the notebook and CSV file from this repository.
2.  Install Python, Jupyter Notebook, and Pandas if needed.
3.  Place both files in the same folder.
4.  Open the notebook in Jupyter Notebook.
5.  Run the cells to view the analysis and results.

## Purpose
This assignment was completed as part of the GSBA coursework to practice Python programming and introductory data analysis.
